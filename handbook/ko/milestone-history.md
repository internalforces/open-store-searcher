# 마일스톤 기록

> 대상: 프로젝트가 단계별로 어떻게 변했는지 확인하려는 사람
> 구현 입력: 아니오
> 기준 상태: M0 완료
> 최종 검토일: 2026-08-24
> 상태: Pre-M0 기준선과 검증된 M0 결과를 기록함

이 기록은 사람이 프로젝트 변화를 이해하도록 요약한 것이다. 개별 작업 로그나 출시 증거를 대신하지 않는다.

## 2026-08-24 — M0 기술 결정과 기반

### 완료하고 검증한 내용

- TypeScript 7.0.2, Node.js 24.19.0 LTS, Preact 10.29.8, Vite 8.2.1과 npm 11.17.0을 승인했다.
- 단일 저장소·단일 패키지 구조와 `src/app`, `src/search`, `src/domain`, `src/pipeline`, `src/shared` 모듈 경계를 만들었다.
- 프로젝트 코드 라이선스를 MIT로 확정하고 직접·간접 의존성의 라이선스 보고 절차를 마련했다.
- 최소 정적 애플리케이션과 개발, 코드 검사, 형식 검사, 타입 검사, 빌드, 미리보기 명령을 구성했다.
- 단위·파이프라인·컴포넌트 테스트 구조와 결정적 오프라인 픽스처 규칙을 만들었다.
- GitHub Pages 하위 경로 형태의 로컬 빌드를 데스크톱 Chromium·Firefox·WebKit과 모바일 Chromium에서 검사하는 기반을 만들었다.
- 데스크톱·모바일 Chromium에서 WCAG 2.1 A·AA 자동 접근성 검사를 실행하는 기반을 만들었다.

### 검증 증거

- TASK-002는 깨끗한 의존성 설치, 코드·형식·타입 검사, 정적 빌드, 하위 경로 산출물과 의존성 라이선스 검사를 통과했고 독립 Tester와 Reviewer의 승인을 받았다.
- TASK-003은 깨끗한 의존성 설치 후 빠른 검증과 전체 검증을 통과했고 독립 Tester와 Reviewer의 승인을 받았다.
- 현재 존재하는 컴포넌트 테스트는 문장·분기·함수·줄 커버리지 100%를 기록했다.
- 네 가지 브라우저 화면 검사와 두 가지 자동 접근성 검사가 통과했으며 자동 접근성 위반은 0건이었다.
- 이 결과는 M0의 최소 화면과 테스트 기반에 대한 것이다. 아직 만들지 않은 검색 제품 전체의 정확도, 성능 또는 접근성 결과가 아니다.

권위 있는 상세 증거는 `reports/test-2026-08-20-task-002.md`, `reports/review-2026-08-20-task-002.md`, `reports/test-2026-08-24-task-003.md`, `reports/review-2026-08-24-task-003.md`에 있다.

### 아직 완료되지 않은 내용

- 공식 원천 데이터의 다운로드 방식, 인증 여부, 스키마, 이용조건과 출처표시 확인
- 상태 코드 상세 매핑과 정적 JSON 스키마
- 데이터 수집·변환·검증·게시 파이프라인과 마지막 정상 데이터의 원자적 보존
- 실제 사업체 검색, 후보 순위, 결과 카드와 오류·오래된 데이터 화면
- 제품 수준의 키보드·스크린리더 수동 검토, 검색 품질과 성능 검증
- GitHub Actions 배포 워크플로, 운영 URL과 실제 GitHub Pages 배포

다음 작업은 M1의 TASK-004다. 공식 원천 데이터 계약을 확인하기 전에는 데이터 필드, 상태 매핑 또는 수집 방식을 확정된 사실로 취급하지 않는다.

## 2026-08-18 — Pre-M0 기준선

### 현재까지 확정된 내용

- 제품 PRD 1.0 검토가 끝났다.
- 제품은 서울 소재 인허가 사업체를 상호명이나 주소로 검색하는 무료 오픈소스 정적 대시보드를 목표로 한다.
- GitHub Actions에서 공개데이터를 가공하고 GitHub Pages가 정적 사이트와 JSON을 제공하며, 검색은 브라우저에서 실행하는 구조가 승인되었다.
- 검색어와 사용 행동을 수집하지 않고 분석·광고·추적 도구를 사용하지 않는 원칙이 승인되었다.
- 화면 상태는 `행정상 영업`, `휴업`, `폐업`, `확인되지 않음`만 사용한다.
- 불확실한 검색, 주소 충돌, 새로운 상태 코드와 데이터 오류는 안전하게 `확인되지 않음`으로 처리한다.
- 새 데이터 검증에 실패하면 마지막 정상 데이터를 유지한다.
- 모든 AI 개발 하네스 문서는 영어로 관리한다.
- 사람을 위한 한국어 설명은 `handbook/ko/`에 분리하고 AI 구현 컨텍스트에서 제외하는 정책이 승인되었다.

### 아직 완료되지 않은 내용

- 언어, 프레임워크, 패키지 관리자, 테스트 도구와 저장소 구조 선택
- 개발·테스트·빌드 명령 구성
- 공식 원천 데이터 계약, 이용조건, 스키마와 출처표시 확인
- 상태 코드 상세 매핑
- 데이터 수집·변환·검증·게시 파이프라인 구현
- 검색 엔진과 대시보드 화면 구현
- 접근성, 검색 품질, 성능, 개인정보와 배포 검증
- GitHub Pages 배포와 v1.0 출시

### 이번에 만든 사람용 문서

- 핸드북 안내
- 프로젝트 개요
- 아키텍처
- 데이터와 상태
- 검색과 화면
- 운영
- 용어집
- 마일스톤 기록

당시 모든 문서는 Pre-M0 상태를 표시했으며, 계획을 실제 구현처럼 서술하지 않도록 검토했다.

### 알려진 제한

- 제품 코드와 실행 가능한 애플리케이션이 아직 없다.
- 데이터 제공 방식과 이용조건이 확인되지 않았다.
- 실제 검색 정확도, 속도, 접근성과 데이터 최신성을 측정한 결과가 없다.
- 당시 작업 디렉터리는 아직 Git 저장소로 초기화되지 않았다.

## 이후 기록 원칙

마일스톤이 끝날 때마다 다음 내용을 한 번만 요약한다.

- 완료일과 기준 마일스톤
- 사용자가 새로 할 수 있게 된 일
- 실제로 검증된 구조·데이터·화면·운영 변화
- 승인된 중요한 결정
- 남아 있는 제한과 다음 단계
- 갱신한 핸드북 문서
- 검토했지만 바꾸지 않은 문서와 그 이유
- 사람의 한국어 검토 완료 여부

진행 중인 작업, 통과하지 않은 테스트와 승인되지 않은 결정은 완료 기록에 넣지 않는다.
