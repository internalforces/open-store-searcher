# 마일스톤 기록

> 대상: 프로젝트가 단계별로 어떻게 변했는지 확인하려는 사람  
> 구현 입력: 아니오  
> 기준 상태: Pre-M0 — 첫 구현 마일스톤 시작 전  
> 최종 검토일: 2026-08-18  
> 상태: 현재 기준선과 문서화 결정을 기록함

이 기록은 사람이 프로젝트 변화를 이해하도록 요약한 것이다. 개별 작업 로그나 출시 증거를 대신하지 않는다.

## 2026-08-18 — Pre-M0 기준선

### 현재까지 확정된 내용

- 제품 PRD 1.0 검토가 끝났다.
- 제품은 서울 소재 인허가 사업체를 상호명이나 주소로 검색하는 무료 오픈소스 정적 대시보드를 목표로 한다.
- GitHub Actions에서 공개데이터를 가공하고 GitHub Pages가 정적 사이트와 JSON을 제공하며, 검색은 브라우저에서 실행하는 구조가 승인되었다.
- 검색어와 사용 행동을 수집하지 않고 분석·광고·추적 도구를 사용하지 않는 원칙이 승인되었다.
- 화면 상태는 `행정상 영업`, `휴업`, `폐업`, `확인되지 않음`만 사용한다.
- 불확실한 검색, 주소 충돌, 새로운 상태 코드와 데이터 오류는 안전하게 `확인되지 않음`으로 처리한다.
- 새 데이터 검증에 실패하면 마지막 정상 데이터를 유지한다.
- 모든 AI 개발 하네스 문서는 영어로 관리한다.
- 사람을 위한 한국어 설명은 `handbook/ko/`에 분리하고 AI 구현 컨텍스트에서 제외하는 정책이 승인되었다.

### 아직 완료되지 않은 내용

- 언어, 프레임워크, 패키지 관리자, 테스트 도구와 저장소 구조 선택
- 개발·테스트·빌드 명령 구성
- 공식 원천 데이터 계약, 이용조건, 스키마와 출처표시 확인
- 상태 코드 상세 매핑
- 데이터 수집·변환·검증·게시 파이프라인 구현
- 검색 엔진과 대시보드 화면 구현
- 접근성, 검색 품질, 성능, 개인정보와 배포 검증
- GitHub Pages 배포와 v1.0 출시

### 이번에 만든 사람용 문서

- 핸드북 안내
- 프로젝트 개요
- 아키텍처
- 데이터와 상태
- 검색과 화면
- 운영
- 용어집
- 마일스톤 기록

모든 문서는 Pre-M0 상태를 표시하며, 계획을 실제 구현처럼 서술하지 않도록 검토한다.

### 알려진 제한

- 제품 코드와 실행 가능한 애플리케이션이 아직 없다.
- 데이터 제공 방식과 이용조건이 확인되지 않았다.
- 실제 검색 정확도, 속도, 접근성과 데이터 최신성을 측정한 결과가 없다.
- 현재 작업 디렉터리는 아직 Git 저장소로 초기화되지 않았다.

## 이후 기록 원칙

마일스톤이 끝날 때마다 다음 내용을 한 번만 요약한다.

- 완료일과 기준 마일스톤
- 사용자가 새로 할 수 있게 된 일
- 실제로 검증된 구조·데이터·화면·운영 변화
- 승인된 중요한 결정
- 남아 있는 제한과 다음 단계
- 갱신한 핸드북 문서
- 검토했지만 바꾸지 않은 문서와 그 이유
- 사람의 한국어 검토 완료 여부

진행 중인 작업, 통과하지 않은 테스트와 승인되지 않은 결정은 완료 기록에 넣지 않는다.
