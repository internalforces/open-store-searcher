# open-store-searcher 사람용 핸드북

> 대상: 프로젝트를 이해하려는 사람
> 구현 입력: 아니오
> 기준 상태: M0 완료
> 최종 검토일: 2026-08-24
> 상태: 사람의 한국어 검토를 통과한 M0 기준선과 아직 구현되지 않은 제품 기능을 구분해 설명함

이 핸드북은 `open-store-searcher`가 무엇을 만들고 왜 그렇게 설계하는지 한국어로 설명한다. 개발을 지시하는 명세가 아니며, AI 구현 에이전트는 이 디렉터리를 구현 근거로 읽거나 사용하지 않는다.

## 현재 한눈에 보기

- 제품 요구사항 검토, AI 개발 하네스 구성과 M0 기술 기반 구현·검증이 끝났다.
- TypeScript 7.0.2, Node.js 24.19.0 LTS, Preact 10.29.8, Vite 8.2.1과 npm 11.17.0을 사용하는 단일 패키지 구조가 승인되었다.
- 최소 정적 화면과 빌드, 코드 검사, 형식 검사, 타입 검사, 단위·컴포넌트·브라우저·자동 접근성 테스트 기반이 실행 가능하다.
- 실제 사업체 검색 화면, 검색 엔진, 데이터 파이프라인, GitHub Actions 배포 작업과 운영 URL은 아직 구현되지 않았다.
- 정적 사이트, 브라우저 검색, GitHub Actions 기반 데이터 가공, GitHub Pages 배포라는 큰 구조는 승인되었다.
- 데이터 제공 방식, 이용조건, 정확한 스키마와 상태 매핑표는 공식 자료를 조사한 뒤 확정한다.

## 반드시 알아야 할 한계

- `행정상 영업`은 공개 행정 데이터에 영업 상태로 기록되어 있다는 뜻이다. 지금 문이 열려 있거나 실제 현장에서 영업하고 있음을 보장하지 않는다.
- 검색 결과가 없다는 사실은 폐업을 의미하지 않는다.
- 데이터에는 기준일이 있으며 신고·갱신 지연이나 원천 데이터 범위 때문에 실제 현장과 다를 수 있다.
- 이름이 같아도 주소가 충돌하면 같은 사업체로 자동 확정하지 않는다.
- 출처와 원본 상태를 함께 확인하고, 필요한 경우 외부 지도 검색 등으로 추가 확인해야 한다.

## 이 핸드북의 효력

이 문서는 이해를 돕는 설명 자료다. 프로젝트 헌법, 원본 PRD, 승인된 ADR, 활성 작업, 실제 코드, 테스트와 검증 결과가 구현의 정본이다. 서로 충돌하면 구현을 이 문서에 맞추지 않고, 마일스톤 종료 후 이 핸드북을 고친다.

## 갱신 방식

각 마일스톤의 구현·테스트·검토가 끝난 뒤 영향을 받은 문서만 갱신한다. 변경이 없는 문서도 검토 여부를 기록하며, 한국어 표현과 안전 관련 의미는 사람이 최종 검토한다. 진행 중인 작업은 완료된 것처럼 이 핸드북에 반영하지 않는다.
