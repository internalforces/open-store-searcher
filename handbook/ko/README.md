# open-store-searcher 한국어 README

`open-store-searcher`는 서울시 인허가 사업체 정보를 사업체명이나 주소로 찾아볼 수 있는 무료 오픈소스 정적 대시보드입니다. 공개 데이터에 기록된 행정 상태와 원본 상태, 데이터 날짜, 검색 결과의 불확실성을 함께 보여 줍니다.

> 현재 기본 빌드는 합성 예시 데이터를 사용합니다. 실시간 사업체 조회 서비스가 아니며, 실제 데이터 공개는 데이터 품질·기준 데이터·호스팅 성능·복구·출시 검토를 마친 뒤에만 가능합니다.

## 결과를 읽는 방법

화면에는 `행정상 영업`, `휴업`, `폐업`, `확인되지 않음`만 표시합니다. `행정상 영업`은 행정 데이터에 영업 상태로 기록되었다는 뜻이며, 지금 실제로 영업 중이라는 보장은 아닙니다. 검색 결과가 없다고 해서 폐업으로 판단하지도 않습니다.

중요한 판단에는 주소와 원본 상태, 출처, 날짜를 함께 확인하고 필요하면 사업체나 다른 공식 경로로 다시 확인하세요. 이름이 같더라도 주소가 다르면 같은 사업체로 자동 확정하지 않습니다.

검색어는 브라우저 안에서만 처리합니다. 이 프로젝트는 분석 도구, 광고, 계정, 검색 기록, 사용 추적을 추가하지 않습니다. 지도 링크를 직접 선택하면 해당 결과의 사업체명과 주소가 지도 제공자에게 전달될 수 있지만, 입력한 검색어가 자동으로 전송되지는 않습니다.

## 시작하기

Node.js 24.19.0과 npm 11.17.0을 설치한 뒤 아래를 실행합니다.

```sh
npm ci
npm run dev
```

표시되는 로컬 주소를 열면 합성 예시 데이터를 확인할 수 있습니다.

변경을 제출하기 전에는 승인된 Ubuntu 24.04 환경에서 다음 검사를 실행합니다.

```sh
npm run verify
```

작업 완료 전 전체 검사는 `npm run verify:full`입니다. 두 개의 수집기 통합 테스트에는 Ubuntu와 Info-ZIP이 필요하므로, 로컬 환경에서 실행할 수 없다면 호스팅된 `Verify` 워크플로를 사용합니다.

## 현재 상태

- 브라우저 검색, 불확실성 안내, 접근성 흐름, 압축 데이터 읽기, 검증 파이프라인, 보호된 GitHub Actions 게시 경로가 구현되고 테스트되었습니다.
- 실제 데이터 게시 설정과 최초 승인 기준 데이터는 아직 없습니다.
- 2026-09-17에 시작한 30일 서울 기준일 원천 데이터 보정 관측이 진행 중입니다.
- 실제 GitHub Pages 배포와 복구 절차는 아직 승인되지 않았습니다.
