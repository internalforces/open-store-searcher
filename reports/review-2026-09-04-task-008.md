# TASK-008 Independent Review

Date: 2026-09-04

Verdict: **Approved for the synthetic, offline implementation scope.** TASK-008 remains open.

## Scope and method

The independent Reviewer inspected the accepted ADR-014 design, project constitution,
standards, active task, traceability, staged validator, metrics and input types, freshness and
JSON helpers, and their tests. Existing collector, transformer, and exact mapper contracts
were checked for consistency. The Reviewer did not author the implementation or tests.
`handbook/ko/**` was excluded throughout.

The review focused on FR-08, FR-13, FR-14 and V01-V13: provenance and ingestion binding,
malformed runtime shapes, baseline integrity, policy arithmetic, unknown status handling,
calendar boundaries, deterministic diagnostics, and the distinction between validation and
publication. No remaining material implementation findings were identified.

## Findings resolved before approval

1. **Medium — sparse evidence arrays could pass validation.** Ingestion headers with the
   correct length but missing elements passed `Array.every`; a sparse allowed-empty list
   could also pass policy checks. The validator now visits sparse elements explicitly and
   checks archive-entry/header/timestamp-field shapes before parsing. Regression tests cover
   sparse ingestion headers, policy lists, archive entries/headers, and permission categories.
   Related: FR-13, V01, V02, V11.
2. **Medium — impossible baseline collision metrics were accepted.** A baseline could report
   collision participants with zero collision groups. Baseline validation now checks group
   and participant relationships, global bounds, and cross-category participation bounds.
   The reproducing regression passes. Related: FR-13, V07, V11.
3. **Low — incomplete policy could conceal malformed supplied values.** Missing fields
   previously took precedence over invalid supplied fields. Policy validation now gives
   invalid values precedence, including nested count/rate/status limits. Three regressions
   cover the root policy, ordinary limits, and status limits. Related: FR-13, V11.
