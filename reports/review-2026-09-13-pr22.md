assets/collected-dataset-<sha256>.json asset. It uses the serialized deployed descriptor's byte
length in pre-copy size accounting and still verifies the complete directory before promotion.
Staging descriptor names and input files are unchanged. The data remains a single file; no
multi-GB duplicate is added. Existing dataset URLs, dataset/baseline bytes and metadata remain.

The deployed reader requires exactly one digest-bound dataset path and baseline.json. It rejects
staging names, mismatched digests, absolute URLs, traversal, duplicate and malformed entries.

The descriptor is now usable to locate every emitted file; this is not a new live dataset
fetch in the baseline reader, nor proof of hosted recovery or production feasibility.
