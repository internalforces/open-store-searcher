# TASK-008 Verification

Date: 2026-09-04. Requirements: FR-08, FR-13, FR-14; accepted ADR-014.
Result: Bounded staged implementation verified. TASK-008 remains open for production evidence
and original-PRD access. No publication or production-readiness claim.

## Environment and test-first evidence

Windows; pinned Node.js 24.19.0 and npm 11.17.0 from the existing temporary official distribution.
The full command prepended that distribution to PATH. Existing dependencies and pins were not
changed; no install or external service was needed.

- Validator's initial narrow run failed because `validate-license-refresh.js` did not exist.
- Helper tests initially failed because their modules did not exist. A calendar year-zero
  regression then exposed an era conversion issue and passed after correction.
- Independent review identified sparse arrays bypassing header/policy checks and impossible
  baseline collision participation. Focused reproduction produced four failures before fixes:
  two false acceptances, one untyped archive-entry exception, and one corrupt baseline acceptance.
  The complete dense-array/collision regression matrix now passes.
- Partial malformed policy regressions produced three failures before correcting result
  precedence. Root, metric-limit, and status-limit errors now reject even if another field is absent.
- No test was disabled to make the new functionality pass. The two existing Windows Info-ZIP
  integration skips remain unchanged.
