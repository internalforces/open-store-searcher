## Scope and provider evidence

Record name plus trimmed road address (parcel fallback) produces fixed HTTPS Naver and Kakao
search destinations. Either available name/address may stand alone; empty, dot-only and malformed
UTF-16 terms return no links. Encoding preserves original term content apart from outer whitespace.
ResultCard keeps status/source/coverage/uncertainty and shows native links with visible new-tab
labels, noopener noreferrer and no-referrer. Synthetic coverage OR synthetic loader provenance
suppresses links. No SDK, dependency, query handler, prefetch, request, analytics or storage added.

- Kakao official guide: https://apis.map.kakao.com/web/guide/ documents
  https://map.kakao.com/link/search/{query}.
- Naver official guide: https://guide.ncloud-docs.com/docs/maps-url-scheme documents the app-only
  nmap scheme. The user explicitly accepted unverified official support/compatibility for the
  proposed HTTPS https://map.naver.com/p/search/{query} route. This is not a documented API or a
  live compatibility guarantee. No headless map page inspection or live provider search occurred.
- Browser fixture uses invented records with unavailable coverage to exercise source-mode UI;
  it is excluded from production and establishes no real-source evidence.
