**Goal:** Implement deterministic browser candidate search with uncertainty safeguards.

## Step 1: Lock the search contract with synthetic tests

Files: src/search/search-candidates.test.ts; .testagent research/plan/status appendices.
API: createSearchIndex(records: readonly unknown[]): SearchIndex; searchCandidates(index: SearchIndex,
original: string): SearchResult. Valid records have id/name/roadAddress/parcelAddress string fields.
Result has validation (PreparedSearchQuery), topMatches, similarCandidates, eligibleCount,
similarCount, primaryMatch (match or null), ambiguousTop, and index diagnostics. A match has record,
score, confidence (high/medium/low), nameMatch, addressMatch and reasons.

- [x] Write S01–S09 fixtures and run the focused command to capture missing-module failure.
- [x] Research module/test pairing once; record unavailable discovery helpers and use a bounded inventory.

Example assertion:
```ts
const index = createSearchIndex([{ id: 'a', name: '봄카페', roadAddress: '강남구 테헤란로 12', parcelAddress: '' }]);
const result = searchCandidates(index, '봄카페 강남구 테헤란로 13');
expect(result.topMatches).toEqual([]);
expect(result.similarCandidates[0]?.confidence).toBe('low');
```
