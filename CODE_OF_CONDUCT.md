# Code of Conduct

## Our commitment

We want participation in `open-store-searcher` to be safe, respectful, and useful. Contributors,
maintainers, and users must treat one another with patience and dignity, including when discussing
data quality, accessibility, safety, or a rejected change.

## Expected behavior

- Give specific, constructive feedback and address the work rather than the person.
- Welcome questions and different levels of experience.
- Respect privacy. Do not publish personal information, private correspondence, credentials, or
  real user search data.
- State evidence and uncertainty honestly. Correct mistakes without blaming the person who found
  them.
- Follow the project's safety, security, and source-attribution rules.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized attention, deliberate intimidation, doxxing,
repeated disruption, or retaliation are not acceptable. Neither is knowingly posting sensitive
security information or personal data in a public thread.

## Reporting and enforcement

For ordinary conduct concerns, contact the repository maintainer through the repository owner's
GitHub profile and avoid public details that could harm someone. For security concerns, follow
[SECURITY.md](SECURITY.md). Maintainers may edit or remove contributions, lock conversations,
issue warnings, temporarily restrict participation, or ban participants when needed to protect the
community.

Reports will be considered in context and shared only as needed to investigate and respond.
Maintainers must disclose conflicts of interest and ask another suitable reviewer to handle a report
when one is available.

This code of conduct applies in project repositories and in other spaces where someone is acting as
a project representative.
